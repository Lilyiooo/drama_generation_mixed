# 直接大纲 + 全历史原文 Baseline 对比结果（v2.4）

## 实验定义

- 生成模型：Qwen3.6-27B。
- 评测模型：Qwen3.8-27B，`drama_evaluator_logic_quality` v2.4。
- 数据：固定同一份世界观、人设、故事总纲和 60 集分集大纲。
- 每种方法运行 R01、R02、R03 三次，每条轨迹 60 集；每条完整轨迹独立评测一次。
- Baseline：第 N 集直接从本集分集大纲生成剧本，并逐字提供该 baseline 已生成的第 1 至 N-1 集全部原文；不使用场次大纲 Agent、状态周期记忆、义务记忆、hybrid 检索、Strategy 卡、门控、桥段检索或生成后改写。
- Candidate：当前 `candidate_gate` 方法。
- Control：当前 `control_hybrid` 方法。

## 主要发现

1. **当前方法明确优于裸 baseline。** Candidate 在逻辑和质量两个总分上均为 3/3 配对全胜，排除了“仅给所有前文就足够”的解释。
2. **最大的逻辑收益来自角色状态与重复控制。** Candidate 相对 baseline 的角色状态提升 10.17 分、重复检测提升 8.67 分，最符合状态周期记忆、检索与门控所针对的问题。
3. **因果、认知、资源和伏笔均有中等收益。** 分别提升 5.83、5.00、4.33 和 4.67 分，说明方法不仅减少显式矛盾，也改善跨集信息组织。
4. **规则时空收益较小。** Candidate 只比 baseline 高 0.83 分，且略低于 Control；时空过渡和世界规则仍是下一步明确短板。
5. **质量收益主要来自人物和钩子。** 人物质量提升 8.33 分，戏剧吸引力提升 6.17 分；桥段、分集剧本、设定质量收益相对较小。
6. **Candidate 更稳定。** 逻辑标准差从 baseline 的 3.04 降到 0.38，质量标准差从 3.37 降到 1.12，说明 Agent/记忆框架显著降低了不同生成 run 的波动。
7. **Candidate 与 Control 存在权衡。** Candidate 的逻辑比 Control 平均高 2.19 分且 3/3 胜，但质量平均低 1.07 分且仅 1/3 胜。当前候选方法是逻辑最优方案，但尚不是质量总分最优方案。

## Baseline 的典型问题

- 关键危机解法和政治转折缺乏充分铺垫，容易依赖临时规则、巧合或反派降智。
- 人物死亡、受伤、知识来源和关键资源在相邻剧集中出现状态断裂。
- “撒泼/舆论施压”“设局—反转—打脸”等模式跨集重复，下一集有时复述上一集结尾。
- 反派和配角的独立目标较弱，主角决策往往始终正确，缺少持续代价和内部两难。
- 部分结尾集明显短于目标字数，但 API `finish_reason=stop`，属于裸模型主动收束而非服务截断；本实验为保持 direct baseline 定义未做后处理重写。

## 结论

在严格相同的大纲与初始设定下，即使 baseline 每集获得此前所有剧本原文，当前 Candidate 仍在三次独立运行中稳定提高逻辑与质量。这说明收益不能简单归因于“看见更多历史文本”，而主要来自结构化状态维护、相关历史检索和生成门控。下一步应保持 Candidate 的逻辑机制，同时针对 Control 更高的桥段质量、钩子和分集剧本表现做质量回补，并单独强化规则/时空一致性。
