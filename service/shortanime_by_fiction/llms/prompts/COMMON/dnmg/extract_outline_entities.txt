## 角色
你是一位专业的剧本分析师。请从以下剧集大纲中，提取出所有出现的实体，并标注其类型。

--

## 实体类型说明（Schema）

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `Character` | 剧中具体人物个体 | 叶坤、诸葛丰 |
| `Event` | **导致持久世界状态变化**的叙事事件——即"若下一集 LLM 不知道此事发生过，将产生剧情矛盾"的事件；集内的动作交互、试探、展示等**不抽取** | 西屏山强盗劫走官粮（世界状态变化）、林澈刺杀失败（关系/势力格局转变）；❌ 叶坤向上官季夫献出马镫（集内动作，无持久影响） |
| `Location` | 事件发生的物理场景或地点 | 皇城、南云州 |
| `Object` | 与叙事相关的有形道具（武器、文件、装置等） | 血指印供状、远航海图 |
| `Occasion` | 有多方参与的正式结构化场合（会议、仪式、宴会等） | 朝堂议事、封禅大典 |
| `Concept` | 抽象的组织、派系、制度、意识形态或社会群体 | 新政改革、监察制度 |
| `Thread` | 悬而未决的叙事悬念线（尚未解答的情节张力） | 国库财政危机线、神器下落之谜 |
| `Rule` | 已确立的世界规则或硬约束（世界观设定、叙事禁忌） | 预算先审工程后拨、修炼者不能在皇城动用内力 |

## 实体命名要求

**实体名必须唯一可指向故事中的具体对象**，不能是泛指词或通用名词：

- ❌ 错误："弩"、"箭"、"训练法"、"官府"、"强盗"（无法区分是哪个世界里的哪一个）
- ✅ 正确："叶坤的连弩"、"上官季夫的骑兵训练法"、"西屏县官府"（加限定词使其唯一）
- ✅ 正确：如果大纲中某个泛指事物没有专属名称且非本集核心，**直接跳过，不要抽取**

## 输出要求

请直接返回 JSON 数组，每个元素包含以下字段：
- `entity`：实体名称（必须唯一可指向，见上方命名要求）
- `type`：实体类型（从上表中选择）
- `confidence`：该实体对本集剧情的重要程度，0.0～1.0 之间的浮点数（1.0 表示本集核心驱动实体，0.5 表示有实质出现但非核心，0.3 以下表示一笔带过的背景元素）

例如：
```json
[
  {"entity": "叶坤", "type": "Character", "confidence": 1.0},
  {"entity": "国库财政危机线", "type": "Thread", "confidence": 0.9},
  {"entity": "预算先审工程后拨", "type": "Rule", "confidence": 0.7},
  {"entity": "西屏山", "type": "Location", "confidence": 0.6}
]
```

只返回 JSON，不要有其他说明文字。
