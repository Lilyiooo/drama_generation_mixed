仔细阅读下面的内容，提取分集大纲，并以JSON格式输出，只输出最后JSON不输出其他信息。

# 分集大纲
```
{EpisodeOutlines}
```

# 输出内容
- episode_number: 集数，数字类型
- episode_title: 本集标题
- chapter_range: 本集主要涉及的小说章节范围，每个元素**必须**是单个数字或'数字-数字'格式的字符串，不需要其它说明文字。比如:["1-4", "6", "8-11"]
- synopsis: 剧情的单集故事梗概。
- events: 列表形式的本集核心事件，列表中的每个元素是一个连续文本字符串，比如“**初入职场**：女主怀着对未来的期待进入一家知名公司，开始了她的职业生涯”
- emotion: 本集核心情绪点, 比如: "甜"
- ending_hook: 本集最后一幕的悬念描述，必须能强烈驱动观众点击下一集。例如：药老提出一个极其苛刻的条件，主角陷入两难，画面定格在他震惊的表情上。

# 输出格式：
```json
{
    "episode_outlines": [
        {
            "episode_number": [Number],
            "episode_title": "",
            "chapter_range": [List],
            "synopsis": "",
            "events": [
                "事件1 ...",
                "事件2 ...",
            ],
            "emotion": "",
            "ending_hook": ""
        },
        {
            "episode_number": 2,
            ... 
        },
        ...
    ]
}
```
