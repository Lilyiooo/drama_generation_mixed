抽取出故事大纲的每一幕的集数范围（！注意是幕次标题对应的集数范围，不是小说章节号），输出JSON格式的抽取结果。
start和end分别表示该幕的开始和结束集数编号，必须为数字类型。

## 故事大纲如下:
```
{ActOutline}
```

## 输出格式
只输出最后JSON，不输出其他多余信息，格式示例如下:
```json
{
    "起": {
        "start": 1,
        "end": 10
    },
    "承": {
        "start": 11,
        "end": 25
    },
    "转": {
        "start": 26,
        "end": 34
    },
    "合": {
        "start": 35,
        "end": 52
    }
}
```
