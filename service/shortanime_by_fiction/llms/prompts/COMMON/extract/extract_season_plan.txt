仔细阅读下面的内容，提取分集大纲，并以JSON格式输出，只输出最后JSON不输出其他信息。

# 分集大纲
```
{EpisodeOutlines}
```

# 输出格式：
```json
{
    "episode_outlines": [
        // 请为每一集生成一个如下结构的对象
        {
            "episode_number": 1, // 集数，数字类型
            "episode_title": "本集标题", // 提炼本集最核心看点的标题
            "chapter_range": ["1-4", "6", "8-11"], // 本集主要改编章节范围，每个元素必须是单个数字或'数字-数字'格式的字符串
            "synopsis": "剧情的单集故事梗概。", // 本集剧情梗概
            "events": [ // 本集核心事件
                "**初入职场**：女主怀着对未来的期待进入一家知名公司，开始了她的职业生涯",
                "事件2：...",
            ],
            "emotion": "甜", // 本集核心情绪点
            "ending_hook": "本集最后一幕的悬念描述，必须能强烈驱动观众点击下一集。例如：药老提出一个极其苛刻的条件，主角陷入两难，画面定格在他震惊的表情上。"
        },
        {
            "episode_number": 2,
            // ... 此处为第二集的内容，结构同上
        }
        // ... 以此类推
    ]
}
```
