## 改编操作说明

根据改编方案，你可以对事件列表进行以下操作：

- **保留**：不需要修改的事件原样保留（id 不变）
- **修改**：调整事件的 title / synopsis / beat_type / drama_weight / characters / locations 等字段（id 不变）
- **删除**：删去与改编方案冲突或不再需要的事件（不在输出列表中出现即为删除）
- **合并**：将多个相关事件合并为一个（使用新 id，如 `{PlotId}-E99`，或复用其中一个 id）
- **新增**：补充改编方案中新增的情节（使用新 id，顺延已有最大编号）
- **重写结局**：修改 beat_type 为 `resolution` 的事件，或新增结局事件

## 注意事项

1. 严格遵循改编方案的意图，不要随意删除与方案无关的事件
2. 保持 plot_id 字段与原事件一致（新增事件指定合理的 plot_id）
3. drama_weight 和 estimated_minutes 需根据改编后的戏剧效果重新评估
4. source_chapters 字段保持与原著对应关系，新增事件若无原著来源可留空 `[]`
5. 输出的是**完整的 G* 事件列表**，包含所有保留、修改、新增的事件

## 输出格式

请严格按以下 JSON 数组格式输出，不要输出额外文字：

```json
[
  {
    "id": "P00-E00",
    "plot_id": "P00",
    "title": "事件标题（10字内）",
    "beat_type": "inciting_incident",
    "drama_weight": 0.8,
    "estimated_minutes": 4.0,
    "characters": ["主角", "反派"],
    "locations": ["宗门广场"],
    "source_chapters": [1, 2],
    "synopsis": "事件简述，100字以内"
  }
]
```
