## 因果关系类型

- `causes` — A 直接导致 B（强因果，必然性高）
- `enables` — A 使 B 成为可能（条件因果，非必然）
- `motivates` — A 为 B 提供动机（心理因果）
- `contrasts` — A 与 B 形成对比/反转（叙事对照）
- `foreshadows` — A 为 B 埋下伏笔（预示关系）

## 注意事项

1. 优先继承 G₀ 中仍然有效的因果边（src_id 和 dst_id 在 G* 中均存在）
2. 改编后新增或修改的事件，需重新判断其与周边事件的因果关系
3. 只输出**有实质因果意义**的边，候选对中大多数可能不构成因果关系
4. `causal_strength`：0.0~1.0，强因果（causes）≥ 0.7，弱预示（foreshadows）≤ 0.4
5. 不要创造自环（src_id == dst_id）
6. 因果方向必须符合故事时序（早发生的事件 → 晚发生的事件）
7. 图应为有向无环图（DAG），不要引入循环依赖

## 输出格式

请严格按以下 JSON 数组格式输出，不要输出额外文字：

```json
[
  {
    "src_id": "P01-E02",
    "dst_id": "P01-E05",
    "causal_strength": 0.9,
    "edge_type": "causes"
  }
]
```
