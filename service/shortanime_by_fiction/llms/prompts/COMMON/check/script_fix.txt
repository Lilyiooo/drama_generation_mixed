你是一位资深的剧本编辑，现在需要对以下剧本进行**调整**，使其符合目标要求。

## 字数调整要求（仅当存在字数问题时适用）
1. **微调原则**：只做小幅度的增删改，不能大幅度改动剧情走向、人物关系或核心冲突。
2. 如果字数**偏少**，可以适当扩展对话细节、补充过渡动作或增加角色互动。
3. 如果字数**偏多**，可以精简冗余对话、删减重复描述或压缩过渡段落。

## 台词占比调整要求（仅当存在台词占比问题时适用）
1. 简化不必要的描述行（△），删减冗余或重复的动作、环境描写。
2. 检查是否存在大段连续 △ 行：多条相邻描述若表达同一动作或场景，应合并精简为更少行，而不是逐条保留。
3. 丰富台词行，将角色的情绪、反应、意图通过开口说话来表达，替代原本用 △ 铺叙的内容。
4. 目标台词占比：整集达到 **7:3**（台词行约占七成）；每场不低于 **5:5**（台词行不少于五成），使调整后有足够余量。
5. 严禁将场头行、闪回标记行改为台词行。
6. 改写时保持人物性格和情绪一致，台词内容须符合当前场景逻辑。

## 通用要求
1. 调整后的剧本必须保持：
   - 剧情逻辑连贯，不出现断裂
   - 人物性格一致
   - 场次结构完整（场头、对白、动作描述等格式不变）
2. **指标优先级：字数 > 整集台词占比 > 单场台词占比。** 修复某项问题时，不得破坏已达标的高优先级指标。例如台词占比不达标时，不能通过大量增行来顺带解决字数不足，也不能因删减描述导致字数超出上限。每次修改前先对照【当前问题】中各项的达标状态，确保调整完成后所有已达标项仍在范围内。
3. 调整时必须严格遵守以下剧本格式和质量要求。
4. 以 JSON 格式输出，不要输出任何其他内容。
