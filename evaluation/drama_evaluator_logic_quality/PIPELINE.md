# 剧本逻辑与质量多 Agent 评测

该目录是从原评测器独立复制出的版本，只评测「剧本逻辑」和「剧本质量」，不调用剧本创意评测。

## 流程

1. 逻辑和质量各调用 3 个独立评审，只发现 S/A/B 问题与亮点并建立证据台账，不输出综合分。
2. 每个大维度各调用 1 个审核模型，合并重复条目、驳回不成立条目并纠正分类和等级。
3. 每个大维度对有争议的条目按需调用 1 个仲裁模型。
4. 每个大维度单独调用 1 次整体评分模型，直接阅读完整剧本并给该维度的各子维度打 0–100 分，不输出大维度综合分。
5. 程序按审核后的 S/A/B 台账计算各子维度台账分，再与独立整体评分做 50/50 融合。
6. 大维度得分取该维度全部子维度融合分的算术平均。

核心调用量为 10–12 次：6 次评审、2 次审核、2 次独立整体评分，以及最多 2 次仲裁。流程只输出评分、证据台账与行为量表诊断，不再调用额外模型生成制作建议。

## 子维度与公式

剧本逻辑最终按 7 个子维度计分：因果链路、角色状态、认知状态、资源状态、规则时空、伏笔闭环、重复检测。

剧本质量最终按 5 个模块计分：人物质量、戏剧吸引力、情节规划质量、分集剧本质量、设定质量。每个模块各自以一份 90 分为台账基线，模块内全部确认问题和亮点直接按照 S/A/B 锚点加扣。12 个底层单元仅作为证据分类，用于定位分数来源和开展论文统计。

- 人物质量汇总主角、配角与角色功能、人物关系台账项。
- 戏剧吸引力汇总开篇叙事吸引力、矛盾建立、集间承接与兑现台账项。
- 情节规划质量汇总桥段质量、情绪节奏、情节结构台账项。
- 分集剧本质量汇总台词质量、视觉化质量台账项。
- 设定质量汇总设定质量台账项。

实际评分 Prompt 以各模块专家角色开场，通过“角色能力—评分任务—证据要求—评分锚点—结构化输出”的正向结构组织指令。评审在发现问题、亮点或给出 1–5 行为等级时提交必要的原文证据。戏剧吸引力评估开篇建立、矛盾建立、集间承接与兑现，指标范围聚焦文本中的戏剧功能。

质量模块内不设置二次权重。例如人物质量出现一个主角 S 级问题时，人物质量台账分直接由 90 分降至 80 分；该问题不会再乘以主角占比。五个模块的融合分最终做算术平均。

情节规划额外输出 11 个检查项的 1–5 行为量表诊断，由 3 名质量评审分别给出。该量表当前只用于论文分析、评审一致性和后续校准，不直接参与 S/A/B 台账计分或最终融合分。

```text
子维度融合分 = (审核后台账分 + 独立整体评分) / 2
大维度得分   = 该大维度所有子维度融合分的算术平均
```

不再使用评审模型顺手给出的综合分、五模块外层权重或质量短板系数计算最终大维度得分。

## 运行

```bash
python evaluate_multi_agent.py <剧本.txt> \
  --output-dir output/<名称> \
  --model qwen-local \
  --context-mode direct
```

`--dry-run` 只检查输入和预计调用量；`--restart` 清理同一输出目录中的旧中间产物后重跑。

主要产物：

- `scores.json`：两个大维度、各子维度台账分、独立整体分和融合分。
- `multi_agent_result.json`：完整机器可读结果。
- `00_多Agent评估报告.md`：可读报告。
- `multi_agent/reviews/`：6 份初审台账。
- `multi_agent/audits/`：2 份审核结果。
- `multi_agent/arbitrations/`：按需仲裁结果。
- `multi_agent/holistic_scores/`：2 份独立子维度整体评分。
